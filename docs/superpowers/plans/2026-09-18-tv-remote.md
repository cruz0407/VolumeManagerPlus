# TV Remote Implementation Plan

**Goal:** A remotely operable Volume Manager TV build without changing its audio engine.
**Architecture:** Route TV launch/configuration to a separate Compose screen. A pure key reducer supplies tested navigation and volume clamping; state is rendered in a keyed LazyColumn and persisted through existing App.volume. Menus and setup use one focusable remote panel with explicit selection, avoiding focus escape.
**Tech Stack:** Kotlin, Compose Material3, existing Shizuku and DataStore.

## Constraints
- Android 13+, preserve upstream audio interception and license.
- Up/down navigation, left/right 5 percentage points, repeat supported, confirm menu, back layered.
- Separate TV application ID; original app untouched; do not claim physical-device verification.
